Luma listens to your music and builds the light show with you. You do not
need to know lighting: build the room, pick a song, and ask.

Under the hood, a show never names a DMX channel. A clip says "pulse
`front_wash` on every fourth beat", and the venue says which of its fixtures
are in `front_wash`. Add or swap lights and every clip follows. To take a
show to another room, ask the agent to refit it.

## Install

On an Apple silicon Mac,
[download Luma](https://github.com/lumashow/luma/releases/latest/download/Luma-aarch64.dmg)
and drag it to Applications.

On Linux x86_64, paste this in a terminal:

```sh
curl -fsSL https://github.com/lumashow/luma/releases/latest/download/install.sh | sh
```

Either way it updates itself from then on. There is no Windows or Intel Mac
build yet.

Sign in when it opens. You need an account to import songs and make changes,
and it keeps your library in sync across your computers.

## Ask the agent

The panel on the left of the window is a chat. It can build a rig, write a
score for a song, lay out a page of pads, and tell you what it did and why.
Rig, each score and Live have a chat of their own.

These docs are short because of it. When you want to know how something
works, ask.

The agent runs on a Claude Code subscription, a Codex subscription or an API
key. Choose one in **Settings → AI** (**⌘,**).

## Three modes

A window shows one venue. Switch modes with the switch in the title bar or
the keys `1`, `2` and `3`. Switching stops nothing: playback, loops and chats
carry on.

| Mode | Key | What you do there |
|------|-----|-------------------|
| [Rig](/docs/rig) | `1` | Build the room: the stage, the fixtures, the patch and the groups. |
| [Arrange](/docs/arrange) | `2` | Write a score on a song's timeline. |
| [Live](/docs/live) | `3` | Follow the DJ and play. |

## Your first show

1. **Make a venue.** It opens in Rig. Press **A** to add trusses and
   fixtures, then **Auto patch** and **Generate from stage** for a starting
   set of groups.
2. **Add a song.** **⌘P** opens the song list. **Add songs** imports from
   Rekordbox, Engine DJ or files. Luma analyzes it in the background.
3. **Write a score.** Open the song, choose **New score**, and ask the agent
   for one, or add clips yourself with **Add pattern**.
4. **Play it.** Press `3`. With no decks connected, the **Virtual** source
   plays any song from your library.

## Keys

Every shortcut is listed in **Settings → Shortcuts**, where you can change
it. Escape closes the innermost thing that is open. On Linux, read ⌘ as Ctrl.
