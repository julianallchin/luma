title: DMX Output Pipeline
description: Lighting state to DMX channel values, strobe handling, color wheels and Art-Net output
---

The DMX pipeline converts lighting states into DMX values and sends them over
Art-Net.

## Lighting state

`PrimitiveState` (in `backend/src/models/universe.rs`) is the state of one
fixture or head at one time:

```rust
pub struct PrimitiveState {
    pub dimmer: f32,        // 0.0 - 1.0
    pub color: [f32; 3],    // RGB [0.0 - 1.0]
    pub strobe: f32,        // 0.0 (off) - 1.0 (fastest)
    pub position: [f32; 2], // [PanDeg, TiltDeg]
    pub speed: f32,         // 0.0 (frozen) or 1.0 (fast) - binary
}
```

`UniverseState` maps an id to a `PrimitiveState`. The id is a fixture id, or a
fixture id and a head index: `fixture-id:0`.

## Channel mapping

File: `backend/src/fixtures/engine.rs`. The function `generate_dmx` writes one
512-byte buffer per universe.

| Channel type | Mapping |
|--------------|---------|
| Master dimmer | `dimmer × 255`, scaled by the Max Dimmer setting. On a color wheel fixture, the dimmer is first multiplied by the color luminance. |
| Red, green, blue | `color × 255` for each channel |
| Color wheel | The nearest wheel color. A black color holds the previous value. |
| Pan, tilt | Signed degrees centered on 0, mapped over the fixture's pan or tilt range to a 16-bit value. A coarse channel gets the high byte. A channel with "fine" in its preset gets the low byte. A NaN value holds the previous value. |
| Shutter | Controlled by the strobe rules below |
| Speed | Speed above 0.5 writes 0 (fastest). Otherwise it writes 255 (slowest). |

The engine does not invert pan or tilt. Pan and tilt go out as the evaluator
produced them.

The Max Dimmer setting is a percentage. Its default is 100.

### Multi-head fixtures

Channels inside a `<Head>` read the state of that head. A master dimmer reads
the fixture state. If there is no fixture state, channels fall back to head 0.

### Color wheels

`map_nearest_color_capability` compares the requested color with the color of
each wheel slot. The distance adds a saturation penalty. A gray request
therefore prefers a white slot over a saturated slot.

## Strobe

The engine picks one method per fixture per frame. It uses the first method
that the fixture supports:

1. Per-head shutter channels.
2. The master shutter channel, if all heads have the same strobe value.
3. A pulse on per-head dimmer channels.
4. A pulse on the master dimmer, if all heads agree.
5. A pulse on per-head color channels.
6. A pulse on the master color channels, if all heads agree.

Two strobe values agree when they differ by less than 1/256. A pulse is a
square wave. Its frequency is `strobe × 20` Hz.

When strobe is 0, the shutter writes its "Open" capability. If the channel has
no "Open" capability, it holds the previous value. When the engine pulses
another channel, the master shutter is set to "Open".

## Art-Net

File: `backend/src/artnet.rs`.

### ArtDmx packet

| Field | Value |
|-------|-------|
| ID | `Art-Net\0` |
| OpCode | `0x5000`, low byte first |
| Protocol version | 14 |
| Sequence | Increments once per frame |
| Physical | 0 |
| Port address | 15-bit universe address |
| Length | 512 |
| Data | 512 DMX values |

### Destinations

- A universe bound to a discovered node goes to that node's IP and port, with
  the node's port address.
- An unbound universe uses the address
  `(net << 8) | (subnet << 4) | (universe & 0xF)`. Universes above 15 alias
  onto 0–15. The engine logs a warning once per universe.
- An unbound universe goes to the unicast IP when one is set. It also goes to
  `255.255.255.255:6454` when broadcast is on or when no unicast IP is set.

### Discovery

Discovery sends ArtPoll (`0x2000`) every 3 seconds. It sends to
`255.255.255.255` and to a directed broadcast address for the local network.
It reads ArtPollReply (`0x2100`) packets to list nodes.

## Output loop

The desktop host runs `run_artnet` in `backend/src/dispatch/services.rs`. Every
23 ms it samples the render engine at the audio playback time and sends the
frame. When output stops, it sends one empty frame.
