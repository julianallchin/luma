title: Node Graph Engine
description: Canonical score graphs, tensor preparation, immutable events, and clip playback
---

Canonical scores own their graph definitions and clip instances. The shared
evaluator in `backend/crates/patterns` computes numerical signals; the backend
supplies venue geometry and analyzed track data, then composites explicit fixture
outputs. Native playback and clip previews use the same prepared program.

## Documents and preparation

A score contains named definitions and clips. A definition is a graph of node
instances, input bindings and named outputs. Built-in recipes use the same graph
format; numerical primitives have one Rust signature and kernel registry.
Each clip supplies timing in beats, a group selection, a seed and input overrides.
An Input node's stable key connects these overrides to the graph; renaming its
display label preserves those connections.

Preparation validates types, rates, required bindings and graph acyclicity, then
flattens nested definitions. Only outputs connected to the calling graph remain
in the program. Unused drum sources, audio analyses and clip-range reductions
are removed before track preparation. A source offering several drums therefore
needs only the analyses used by its connected outputs.

Fixed computations, including mappings and immutable event lists, are prepared
once. Clip-range reductions sample their upstream dependencies over the clip;
they are reused during playback. Rebinding analyzed track data rebuilds these
prepared values. Playback executes the remaining dependencies in order without
walking the authored definitions again.

Key files: `backend/crates/patterns/src/graph.rs`, `prepared.rs`, `score.rs`,
and `backend/src/services/graph_scores.rs`.

## Signals and controls

Numerical values are tensors with fixture, time and channel axes. Singleton axes
broadcast; fixture identities, physical units and channel meanings constrain
compatible connections. Scalars, colors, spatial fields and movement vectors use
the same arithmetic operations. A Chase value can drive brightness, be remapped
into pan/tilt, or become a palette coordinate.

Envelopes, gradients, mappings, dropdown choices, audio source descriptions and
events remain structured values. Nodes consume these directly; the graph does
not expand curve construction into stage-specific arithmetic nodes.

## Events and envelopes

Events are immutable timestamps or periodic schedules. They may broadcast across
a selection or carry head targeting. Random targeting derives from the seed,
event identity and head identity, so seeking does not reroll an event.

Event age is evaluated from the requested time. Broadcasting event ages against
head coordinates produces independent Chase journeys; Max combines overlapping
responses. Trigger spacing and journey duration are independent. A completed
journey contributes zero even when the drawn curve ends above zero.

Envelope is one editable curve represented by anchors and optional Bézier handles.
Its numerical sampler preserves fixture, time and channel dimensions. Coincident
anchors express instantaneous steps, with the rightmost anchor winning at the
boundary. Saved stage controls are converted into ordinary curve data on import.

## Timing and output

The host converts absolute track seconds to musical beats using the analyzed beat
timeline, including tempo changes. Seconds and beats have distinct units. The
evaluator accepts arbitrary sample times: playback, out-of-order scrubbing and
batch rendering use the same calculations without a fixed simulation rate or
playback history.

Output accepts independent color, dimmer, pan, tilt, strobe and movement-speed
signals. Leaving a capability unwired differs from writing zero. The host
compositor layers active clips in their authored order and blend mode, with each
clip active over its half-open time span.

The native visualizer auditions an isolated clip with real audio, selection and
overrides. Additional numerical, event and audio outputs can be inspected beside its
transport. Audio outputs display a mel spectrogram of the connected source and
filter chain, with a temporary beat overlay. Signal plots retain head and channel identity; event ticks use the
track's beat timeline. Plots are sampled when the clip changes and cached while
the transport moves. Inspection preferences and the preview cursor are temporary.

## Venue selection and historical documents

Scores target group names rather than physical fixture IDs. The backend resolves
the clip's selection expression against the current venue, enumerates its heads
and supplies their world and UVZ coordinates to the evaluator. The resulting
domain travels with numerical fields so unrelated selections cannot silently mix.

Historical graph conversion lives in `backend/src/node_graph/migration` and
`backend/src/services/graph_scores/migration.rs`. It preserves authored bindings
and records intentional behavior changes against frozen reference results.
Saved standalone graphs also cross this import boundary before playback. The
old category compiler and operation dispatcher have been removed; the host
adapter only prepares track data, projects canonical output into fixture
capabilities, and publishes diagnostics. An unfinished graph receives an
explicit unwritten Output and remains editable.
