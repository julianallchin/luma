Luma uses fixture definitions in the QLC+ format. The fixture system reads
these definitions and computes the position of each head on a fixture.

## QLC+ format

File: `backend/src/fixtures/parser.rs`

Definitions are `.qxf` XML files. `parse_definition` reads one file with
`quick-xml`. `build_index` walks the library and lists every
`Manufacturer/Model.qxf` file. If a file name starts with the manufacturer
name, the index removes that prefix from the model name.

The parser reads:

- **Channels**: name, preset, group and capabilities (DMX ranges, presets, colors and labels).
- **Modes**: channel lists and head definitions.
- **Physical**: dimensions, layout grid and pan/tilt ranges.

## Channel types

`Channel::get_type` in `backend/src/models/fixtures.rs` sets the channel type.

1. It checks the preset first. A preset that starts with `Intensity` is
   Intensity. `Color` or `Colour` is Colour. A preset that contains `Pan`,
   `Tilt`, `Shutter` or `Strobe` is Pan, Tilt or Shutter.
2. Then it checks the group: Intensity, Colour, Pan, Tilt, Beam, Shutter,
   Speed, Gobo, Prism, Effect, Maintenance or Nothing.
3. With no group, it reads the channel name.

The [DMX pipeline](/docs/architecture/dmx-pipeline) uses these types to map
lighting states to channels.

## Head layout

File: `backend/src/fixtures/layout.rs`

`compute_head_offsets` gives each head an offset from the fixture center, in
millimeters:

1. It finds the active mode. With no mode or no heads, it returns one head at
   the center.
2. It reads the physical dimensions and the layout grid. With no dimensions,
   every head is at the center.
3. Cell size is `width / grid_width` by `height / grid_height`.
4. If there are fewer heads than cells, and the cells divide evenly, each head
   takes a group of cells. The head is at the center of its group.
5. Heads fill the grid row by row. X is across the housing. Z is up the
   housing. Y is 0.

`head_geometry` converts the offsets to meters. The `fixture-kinematics`
crate (`rig_position`) combines them with the fixture mount to give world
positions. World space is Z-up, right-handed, in meters: +X stage right, +Y
upstage, +Z up.

### Example: 4-head LED bar

A fixture is 1000 mm × 100 mm, with a 12 × 1 layout grid and 4 heads:

- Cell size: 83.3 mm × 100 mm.
- 4 heads in 12 cells: 3 cells per head.
- Head X offsets: −375 mm, −125 mm, +125 mm, +375 mm.

## Fixture library

The library is in `resources/fixtures/2511260420`. It has one directory per
manufacturer:

```
resources/fixtures/2511260420/
  Chauvet/
    Chauvet-COLORband-PiX-M-USB.qxf
  Martin/
    Martin-MAC-Aura.qxf
  Generic/
    Generic-Dimmer.qxf
```

`resolve_fixtures_root_from` in `backend/src/services/fixtures.rs` finds this
directory. A debug build tries the source tree first. A release build tries the
bundled resource directory first.
