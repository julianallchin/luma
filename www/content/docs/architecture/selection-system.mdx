The selection system turns a group expression into a list of fixture heads.
It is the mechanism that lets a score play in different venues.

## Selection expressions

File: `backend/src/services/groups.rs`

An expression combines group names with operators. A name matches the fixtures
in the group with that snake_case name in the current venue. The keyword `all`
matches every fixture.

```
all                          -- every fixture in the venue
front_wash                   -- fixtures in the front_wash group
front_wash & left_truss      -- fixtures in both groups
left_truss | right_truss     -- fixtures in either group
floor_ring & ~dj_booth       -- floor_ring fixtures not in dj_booth
strobes > front_wash         -- strobes; front_wash if strobes matches nothing
```

### Operators

The parser gives these operators precedence from lowest to highest:

| Operator | Name | Meaning |
|----------|------|---------|
| `>` | Fallback | Use the left side. If it matches nothing, use the right side. |
| `\|` | OR | Either side matches |
| `^` | XOR | Exactly one side matches |
| `&` | AND | Both sides match |
| `~` | NOT | Negates the next term |
| `( )` | Grouping | Changes the order |

## Subsets

A selection has an expression and a subset (`Selection` in
`backend/crates/patterns/src/selection.rs`). The subset decides how many of the
matched fixtures stay:

| Subset | Meaning |
|--------|---------|
| `all` | Every match. This is the default. |
| `{"fraction": f}` | `f` of the matches, rounded to nearest, at least one |
| `{"count": n}` | `n` matches, clamped to the number of matches |

A seed decides which fixtures stay. The same seed always keeps the same
fixtures. When every match is a whole fixture, the subset picks whole fixtures.
When a match covers only some heads of a fixture, the subset picks heads. The
result keeps venue order.

## Cells

A graph does not reference fixtures. The host resolves the selection of each
clip and gives the engine a list of `Cell` values
(`backend/crates/patterns/src/mapping.rs`):

| Field | Meaning |
|-------|---------|
| `id` | Head identity |
| `group` | Group name |
| `world` | Position in venue space: X stage right, Y upstage, Z up |
| `uvz` | Position in stage space |

`Cell::stage_coordinates` converts venue space to stage space: U right, V
downstage, Z up.

## Mapping sources

The `resolve_mapping` node turns cells into a coordinate from 0 to 1. The
source is one of:

| Source | Meaning |
|--------|---------|
| `z` | Up |
| `u` | Stage right |
| `v` | Downstage |
| `major_axis` | The principal axis, with its sign set by an authored direction |
| `circle` | The angle on a fitted circle, with an authored origin |
| `order` | Selection order |
| `vector` | A custom direction in stage coordinates |

A mapping can also run per group and in reverse.

## Rig UV

File: `backend/src/node_graph/geometry.rs`, function `rig_uv`.

`rig_uv` gives each position a `(u, v)` pair from 0 to 1 over the selection:

- **`u`** is the first principal component of the horizontal (XY) spread. Its
  sign is set so that its largest world component is positive. With no
  horizontal spread, `u` is the normalized index.
- **`v`** is world height (Z) over the selection. With no height spread, `v`
  is 0.5.

The agent venue tools use `rig_uv`
(`backend/src/agent_execution/bindings/providers/venue.rs`).

## Circle fitting

File: `backend/crates/patterns/src/circle_fit.rs`

`fit_circle_3d` fits a circle to three or more 3D points. The `circle` mapping
source and the `core/fit_circle` node use it.

1. **Centroid**: the mean of the points.
2. **Plane**: PCA on the covariance matrix. Power iteration (20 steps) with
   deflation gives the two main axes.
3. **Projection**: each point is projected onto the plane.
4. **RANSAC**: 100 iterations. Each iteration fits a circle through 3 random
   points and counts inliers within 2.5 units. It stops early when 90% of the
   points are inliers. The pseudo-random seed is fixed, so the result is
   repeatable.
5. **Refinement**: a Kåsa fit on the inliers.
6. **Angles**: `atan2` of each projected point around the center, normalized
   to 0–1 and offset so that 0 is at the top.
