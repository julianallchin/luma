# Create Groups

A score never refers to a fixture id. It refers to **groups** of its venue. Each venue defines its own groups. When a score plays, Luma lights the fixtures that are in the groups its clips select.

## What a Group Is

A group is a named set of fixtures in one venue. Example names:

- `front_wash`
- `back_movers`
- `floor_ring`
- `dj_booth`

A clip that selects `front_wash` lights the fixtures that are in `front_wash` when it plays. Change the fixtures in the group, and every clip that selects it follows.

### Group Names

Luma changes group names to snake_case. It makes letters lowercase, changes spaces and hyphens to underscores, and removes other characters. A name must match `[a-z][a-z0-9_]*`. A name cannot be `all`, because `all` selects every fixture.

## Make Groups

Groups are on the venue page in **Rig** mode, beside the patch, under the stage.

- **Generate from stage.** This button shows when the venue has no groups. Luma makes a starting set of groups from the rig. It groups fixtures by role (for example wash, spot, beam, strobe, blinder, pixel and fx), by where their structure sits, and by how they split: top and bottom, left and right, downstage and upstage.
- **New group.** Select fixtures in the table or on the stage, click **New group** and type a name. The group holds the fixtures that you selected.

Generation gives only a starting set. You can rename and change groups after that.

### Change What a Group Holds

Click a group to select its fixtures. To add or remove fixtures, select them, then click the box beside the group. A tick shows that the group holds all the selected fixtures, and a dash shows that it holds some of them. The change is saved at once.

Each fixture's row in the table shows the groups that it is in.

### Rename and Delete

Right-click a group to rename or delete it. A clip keeps a reference to the group, not to its name. You can rename a group and every score still selects it.

Deleting a group breaks what selects it. Each clip, live pattern and group cell that selected the group lights nothing there. Before you confirm, Luma tells you how many times the group is used and in how many scores. The fixtures stay in the venue.

## Axis Values

A saved group can have three axis values. Each value is from -1 to +1.

| Axis | -1 | +1 |
|------|----|----|
| `axis_lr` | Left | Right |
| `axis_fb` | Front | Back |
| `axis_ab` | Below | Above |

Groups that are generated and not saved have no axis values.

## Selections

A clip's selection is every fixture in the venue, or one or more groups. With more than one group, the clip lights the fixtures in any of them.

Where you type a selection, write group names:

| Text | Result |
|------|--------|
| `all` | Every fixture in the venue |
| `front_wash` | Fixtures in `front_wash` |
| `left_truss \| right_truss` | Fixtures in either group |

Luma refuses a name that the venue has no group for.

A selection cannot combine groups in another way. For the fixtures that two groups share, or one group without another, make a group that holds those fixtures.

## Name Groups

Use the same names in every venue, so that you and the agent ask for the same thing everywhere. Name a group by its role, its position, or both:

| Style | Examples |
|-------|----------|
| Role | `wash`, `strobes`, `movers` |
| Position | `front`, `back`, `ceiling`, `floor` |
| Both | `front_wash`, `back_movers`, `floor_ring` |

A score belongs to one venue and selects that venue's groups.
