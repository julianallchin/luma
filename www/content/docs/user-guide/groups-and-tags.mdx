# Create Groups

A score never refers to a fixture id. It refers to **group names**. Each venue defines its own groups. When a score plays, Luma resolves the group names against the current venue.

## What a Group Is

A group is a named set of fixtures in one venue. Example names:

- `front_wash`
- `back_movers`
- `floor_ring`
- `dj_booth`

If two venues both have a group called `front_wash`, a clip that selects `front_wash` works in both venues. The fixtures in the two groups can be different models.

### Group Names

Luma changes group names to snake_case. It makes letters lowercase, changes spaces and hyphens to underscores, and removes other characters. A name must match `[a-z][a-z0-9_]*`. A name cannot be `all`, because `all` selects every fixture.

## Make Groups

Groups are in the venue tab, next to the patch and the stage.

- **Generate from stage.** This button shows when the venue has no groups. Luma makes a starting set of groups from the rig. It groups fixtures by role (for example wash, spot, beam, strobe, blinder, pixel and fx), by where their structure sits, and by how they split: top and bottom, left and right, downstage and upstage.
- **Create group.** Make a group by hand.
- **Group selected lights.** Make a group from the fixtures that you selected.

Generation gives only a starting set. You can save, rename and change groups after that.

### Missing Groups

A score can refer to a group that the venue does not have. The groups panel then shows **missing groups · Resolve**. The repair dialog lets you replace each missing name with a name that exists, and then **Fix affected scores**.

## Axis Values

A saved group can have three axis values. Each value is from -1 to +1.

| Axis | -1 | +1 |
|------|----|----|
| `axis_lr` | Left | Right |
| `axis_fb` | Front | Back |
| `axis_ab` | Below | Above |

Groups that are generated and not saved have no axis values.

## Selection Expressions

A clip's selection is an expression over group names.

| Operator | Name | Example | Result |
|----------|------|---------|--------|
| `&` | And | `front_wash & left_truss` | Fixtures in both groups |
| `\|` | Or | `left_truss \| right_truss` | Fixtures in either group |
| `^` | Either | `left_truss ^ right_truss` | One side. If both sides match fixtures, Luma picks one side at random. |
| `~` | Not | `floor_ring & ~dj_booth` | Fixtures in `floor_ring` that are not in `dj_booth` |
| `>` | Fallback | `strobes > front_wash` | The left side. If the left side matches no fixtures, the right side. |

Use parentheses to group terms: `(left_truss | right_truss) & front_wash`.

`>` binds most loosely. An empty expression or `all` selects every fixture in the venue.

## Name Groups for Portability

Use the same names in every venue. Name a group by its role, its position, or both:

| Style | Examples |
|-------|----------|
| Role | `wash`, `strobes`, `movers` |
| Position | `front`, `back`, `ceiling`, `floor` |
| Both | `front_wash`, `back_movers`, `floor_ring` |

Use `>` to give a fallback when a venue does not have a group.
