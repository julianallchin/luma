# Clips and Presets

Every clip owns one small **graph**. The graph says what the clip does to the lights: which color, which pattern across the lights, where moving heads point, how a strobe runs. A **preset** is a shipped graph with a name and a blend mode, such as Chase or Rainbow. Adding a preset copies its graph into the new clip. After that the clip's graph is its own: editing it never changes the preset or another clip.

The patterns of a venue's Perform set, in [Live](/docs/user-guide/performing) mode, are graphs too, and edit the same way.

## Add a Clip

In **Arrange**, click **Add pattern** in the strip above the timeline, or right-click the timeline. The **Insert pattern** dialog opens:

- It lists the shipped presets, then three blank starts: **Color**, **Aim** and **Strobe**. A blank start is a graph with only its output node.
- Type to search. Use ↑ and ↓ to move and ↵ to insert.
- The right side plays a looping preview of the highlighted preset on the venue.

The new clip starts at the playhead and lasts one bar, or fills the span you selected on the timeline.

In **Live**, adding a pattern to a cell lists the presets by name. **Browse with previews…** opens the **preset browser** instead. It groups the presets by output: Color, Aim, Strobe and Laser. Each row has a strip of the preset: time across, heads down. Click a row to start a new pattern of the set from it.

The [preset reference](/docs/node-reference/presets) lists every shipped preset.

## The Graph

A graph has 1 to 64 nodes. Exactly one node is the **output**: color, aim, strobe or laser. The output decides what the clip drives and which blend modes it can use. The other nodes feed it:

| Nodes | What they give |
|-------|----------------|
| Time, Space, Along, Random, Audio, Fader, Button | A raw coordinate at each head: a clock, a place on a ruler across the heads, a random value, the level of a frequency band, a live control |
| Curve, Math, Value | A number, a vector or a color. A curve is the only node that turns a coordinate into a value |
| Mirror, Shuffle, Group, Split | A changed set of heads: folded, in a random order, merged into units, or split into spans |
| Figure | A laser figure, for a laser output |

An input holds a value, a wire from another node, or nothing. An empty input has a meaning of its own, such as "once over the clip" or "best fit". A choice, such as a space's kind, is a setting on the node.

The [node reference](/docs/node-reference) lists every node kind with its inputs, units, ranges and empty values.

### Example: Chase

The Chase preset has five nodes:

1. `t`, a **Time** node with every 2: a clock that runs 0 to 1 every 2 beats.
2. A **Curve** over `t` that ramps from −0.2 to 1.
3. `place`, a **Space** node along the heads. The curve moves its `shift`, and its `scale` is 0.2, so a window a fifth of the heads wide slides across them.
4. A **Curve** over `place` shaped as a pill: 1 inside 0–1, 0 outside.
5. A **Color** output whose brightness is that curve.

In Python it reads:

```python
t = time(every=2)
place = space(shift=curve(t, "Ramp up", low=-0.2, high=1), scale=0.2)
color(brightness=curve(place, [[0, 0], [0, 1], [1, 1], [1, 0]]))
```

## Edit a Graph

Double-click a clip to open its graph. The graph page takes the timeline's place under the stage; **Timeline** at its top, or Escape, goes back. Above the graph are the clip's **Name**, **Selection** and **Blend**. The stage keeps playing the score with your edits while the page is up, and **⌘Z** still undoes.

The graph is a canvas of node cards. Sources are on the left and the output is on the right. The layout is automatic: the same graph always looks the same. Each card shows the node's settings and one row per input. A value input shows its control. A wired input shows a port, and the wire says where its value comes from. Each wire takes the color of what it carries.

Each input row has a **source chip**. It reads **Value** when the input holds a value. Pick another source to wire one in:

- A number, vector or color input offers **Value**, **Over time**, **Over space**, **Random**, **Audio**, **Fader** and **Button**. Picking one adds that node and a curve that maps it to the input's range. **Math** multiplies what the input holds by a new factor. A laser figure's inputs also offer **Along each element**.
- A heads input offers **All**, **Mirror**, **Shuffle**, **Group** and **Split**.
- **Link…** wires the input to a node already in the graph, so two inputs share it.

On the canvas:

- **Add node**, or a right-click on the canvas, adds a node. It joins the graph once its output is wired.
- Drag from an output port onto an input port to wire them. An input that cannot take the wire refuses it with a message.
- Drag a wire off an input and drop it on nothing to unwire it. The input goes back to a value.
- Double-click a card's title, or right-click the card and pick **Rename**, to rename a node.
- The card's ×, **Delete** in its menu, or the Delete key removes a node. Each input it fed goes back to a value.
- The wheel, a pinch, or `+` and `-` zoom. A trackpad scroll or a drag on the ground pans. `0` is actual size, and **Fit** brings the whole graph back into view.

A drag is one undo step. The timeline shows each clip as its name and a one-line summary of its graph, such as `line · every 2`. The clip's fade handles on the timeline edit its output's alpha.

## Colors

Luma keeps colors in Rec. 2020, a wider range than a screen's sRGB. LED fixtures can make many colors outside sRGB: deep red, cyan, lime and royal blue. The color picker reaches all of Rec. 2020. The hex field is sRGB. When a color is outside sRGB, the field shows the nearest sRGB color and says **Outside sRGB**.

A fixture or a screen that cannot make a color shows the nearest color it can make. That color has the same hue and lightness, with less saturation.

## Agents

The chat writes graphs as Python, with one builder per node kind: `time()`, `space()`, `curve()`, `color()` and so on. A node's name in the code is its name on the card. Ask the chat for a look, and it adds or changes clips with these graphs. The [node reference](/docs/node-reference#python) shows each builder.
