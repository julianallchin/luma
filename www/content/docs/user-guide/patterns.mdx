# Define Patterns

A pattern is a graph of nodes. Each node reads values on its input ports and writes values on its output ports. Wires connect an output to an input. A lighting graph ends in the **Apply** node, which writes color, pan, tilt, strobe and movement speed to the selected heads.

## Open a Graph

Double-click a clip in the track editor. Its graph opens in a graph tab. The graph tab evaluates the graph against that track and that venue, so you can preview it. Use **Refresh preview** to run the preview again.

Built-in definitions from the standard library are read-only. The graph tab marks them **BUILT-IN · READ ONLY**.

## Add Nodes

The node catalog is a searchable list of the standard library. It also has an **Input** entry. The catalog lists `core/` nodes after the other nodes. It does not list complete clip graphs, except for Apply.

## Ports

Each port has a value type and a rate.

- **Value type.** A signal has a unit and a channel layout. The units are number, beats, proportion (0–1), position, degrees and seconds. The layouts are one value, RGB, pan/tilt and N components. Number, proportion and position can connect to each other. Other types, such as Events, Envelope, Gradient and Audio source, connect only to the same type.
- **Rate.** A `fixed` value does not change during the clip. A `frame` value can change on every frame. A frame wire cannot connect to a fixed input.

An input that is not wired uses its default value.

The Apply node's inputs are optional. An Apply input that is not wired leaves that capability unchanged.

## Walkthrough: Beat Pulse

**Goal:** the selected heads flash a color at a steady beat interval and fade out.

This graph is the same as the built-in `beat_pulse` graph.

### 1. Add a Beat trigger

Add **Beat trigger** (`beat_trigger`). It writes an event stream on its `trigger` output.

| Input | Default | Meaning |
|-------|---------|---------|
| `repeat` | 4 beats | Time between events |
| `delay` | 0 beats | Moves each event later |
| `grid_aligned` | false | If true, events count from beat 0 of the track. If false, they count from the clip start. |

### 2. Add a Pulse

Add **Pulse** (`pulse`). Connect Beat trigger `trigger` to Pulse `trigger`. Each event starts a separate pulse.

| Input | Default | Meaning |
|-------|---------|---------|
| `duration` | 2 beats | How long each pulse lasts |
| `shape` | 1 → 0 | Brightness over each pulse. Edit the curve in the inspector. |

Pulse writes a 0–1 value on its `mask` output.

### 3. Add an Input and a Multiply

Add an **Input** and name it `Color`. Add **Multiply** (`core/multiply`). Connect the Input to Multiply `a`. Connect Pulse `mask` to Multiply `b`. The `value` output is the color, scaled by the pulse.

### 4. Add Apply

Add **Apply** (`output`). Connect Multiply `value` to Apply `color`. Leave the other Apply inputs unwired.

## Graph Inputs Become Clip Inputs

The inputs of a graph show in the clip inspector when the graph is placed as a clip. In the walkthrough, `Color` shows as a color control. Each clip also has a **Selection** input. It holds the [selection expression](/docs/user-guide/groups-and-tags#selection-expressions) that picks the heads.

The graph never names fixtures. The selection decides which heads the graph runs on.

## Other Built-in Graphs

The standard library has complete graphs that you can place as clips or open and study. Some examples:

| Id | Name | What it does |
|----|------|--------------|
| `beat_chase` | Beat chase | A stroke travels across the mapped heads on each event |
| `beat_pulse` | Beat pulse | The walkthrough above |
| `band_pulse` | Frequency pulse | Brightness follows the energy in a frequency band of an audio source |
| `drum_pulse` | Drum pulse | A fade starts on each hit of one drum |
| `harmony_color` | Harmony color | Color follows the chord root, from a gradient of 12 pitch colors |
| `strobe` | Strobe | A color with a strobe rate |

The [recipes](/docs/node-reference/recipes) page shows how these graphs are built. The [node reference](/docs/node-reference) lists every node.
