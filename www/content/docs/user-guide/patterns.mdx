# Forms and Presets

A clip plays one **form**. A form is a shipped graph with a fixed set of inputs. The clip holds a value for every input of its form. A named look, such as Chase or Rainbow, is a **preset**: saved input values of one form.

## Forms

| Form | What it does |
|------|--------------|
| `color.constant@1` | All selected heads one color, at a brightness that can follow each hit |
| `color.time@1` | A color gradient over time, all heads equal |
| `color.space@1` | A gradient laid across the rig. Each head gets a fixed color from its position |
| `color.chase@1` | Strokes travel across the heads. Each event starts one stroke |
| `color.sparkle@1` | Each event lights a random share of the heads |
| `color.noise@1` | Soft brightness that wanders across space and time |
| `strobe.constant@1` | Fixture shutter strobe at Rate × Alpha |
| `aim@1` | Points moving heads: a base aim, a fan across the axis and a motion shape |

The id of a form never changes meaning. A new meaning is a new version.

Every form has an **Alpha** input. Alpha is how much the clip counts. For light it multiplies the clip's brightness. For aim it is the blend toward the clip's aim.

## Input Values

An input takes a fixed value, or a **source** where the form allows it:

| Source | Meaning |
|--------|---------|
| Fixed | One value, on all heads, for the whole clip |
| Over time | One curve over the whole clip, all heads equal |
| Per hit | One curve over the life of each event |
| Noise | Smooth random wandering over time |
| Audio | The energy of one frequency range of the track's full mix |

## Add a Clip

Open the picker in the track editor. It lists the presets. Choose one. Luma copies its values into a new clip. Edit the inputs in the clip inspector.

Layers combine forms. For a rainbow that chases, put a color layer under a chase layer in `multiply`.

The [node reference](/docs/node-reference/forms) shows the inputs of each form.
