# Settings and Shortcuts

**⌘,** (or **Settings…** in the venue menu) opens the settings page in place
of the window's content. **Back** in the title bar, or Escape, returns to what
was there.

![The settings page on its Shortcuts section: the sections and search on the left, each command and its key on the right.](/screenshots/settings.webp)

The search at the top of the side bar looks through every section's labels
and help text, and lists the matching rows under their section. Escape clears
the search first.

## Sections

| Section | What it holds |
|---------|---------------|
| **General** | **Enable Audio Output**: when it is off, playback keeps time but makes no sound. **HDR output**: on a display that supports HDR, bright stage light can go above the white of other windows. **Show frame rate on the stage**: the frames per second in the stage's corner, which opens the frame stats; on by default. |
| **Account** | Who the library belongs to, and **Sign in** or **Sign out**. |
| **AI** | The **Default agent engine** for new conversations: an API service, a Codex subscription or a Claude Code subscription. With an API engine, the default service and model, and an API key for each service. Keys stay on this device and do not sync. |
| **DMX Output** | **Max Brightness**, **Enable DMX Output** and the Art-Net interface. See [DMX Output](/docs/user-guide/performing#dmx-output). |
| **Shortcuts** | Every rebindable shortcut. See below. |
| **About** | This copy's version, and **Update automatically**. |

A conversation can use another service and model than the default: choose
them beside its message box.

## Shortcuts

**Settings → Shortcuts** lists every shortcut a person can change, by group.
Click a shortcut's keys, then press the new key. Escape stops recording. A key
that another command already uses where this one works is refused, and the
page names that command. **Reset** beside a changed shortcut puts its default
back, and **Reset all** puts every default back.

The menu bar and the key hints in the app follow your changes at once.
Shortcuts are kept per machine and do not sync. A shortcut on a key that
types, such as a bare letter, never fires while a text field has the
keyboard.

On Windows and Linux, read ⌘ as Ctrl. The editing chords also answer to Ctrl
on macOS.

the Rig keys on the stage builder, the Venues keys in the venue dialog.

Escape is not in the table. It always closes the innermost thing that is open.
The arrow keys and Return of lists and menus are not in it either.
