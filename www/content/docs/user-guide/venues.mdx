# Define Your Venue

A venue is one physical room. It holds the fixtures in the room, their DMX addresses, their positions, the stage pieces and the groups.

## Tabs

The workspace has two kinds of tab scope:

- **Venue.** One venue. The venue tab holds the patch, the stage and the groups.
- **Track.** One track in one venue. It holds the track editor and graph tabs.

## Patch Fixtures

The patch table lists each fixture with its **Mode**, **Universe** and **Address**.

1. Click **Add fixtures**. Search the fixture library. Luma ships a library of QLC+ fixture definitions.
2. Choose the **Mode**. The mode sets how many DMX channels the fixture uses and what each channel does. Choose the mode that is set on the real fixture.
3. Set the **Universe** and **Address**, or let Luma pick them. **Auto patch** assigns addresses for you.

The backend assigns every address. The patch page shows an error when the backend refuses an address.

A universe has 512 channels. A fixture that uses 16 channels and starts at address 33 uses channels 33 to 48.

## Build the Stage

The stage page is the only place where you set positions.

- Choose a piece from the palette, such as a truss, and place it.
- Drag a fixture from the tray onto the stage.
- A piece snaps to a socket first, then to the surface under the cursor, then to the ground grid.

Positions use a Z-up, right-handed coordinate system in metres.

### Why Positions Matter

Graphs can use head positions. A chase can travel from one side of a group to the other. A graph can fit a circle to a ring of fixtures. Because these nodes read positions, the same graph works with 8 fixtures or 80.

## Multi-Head Fixtures

Some fixtures have many parts that Luma controls one by one, such as the cells of a pixel bar. Luma calls each part a **head**. Output state is keyed by `fixture-id:head-index`. Graphs run per head, so spatial effects work at the level of each cell.

## View the Rig

The visualizer shows the venue in 3D. The camera button opens **View settings**:

| Setting | Meaning |
|---------|---------|
| **Environment** | Indoor or outdoor |
| **Haze** | Turns volumetric haze on or off |
| **Haze density** | How thick the haze is |
| **Cloudiness** | How uneven the haze is (0–1) |
| **Cloud size (m)** | Size of the haze clouds |
| **Turbulence** | How much the haze moves (0–1) |
| **Wind speed (m/s)** | Speed of the haze drift |
| **Wind direction (°)** | Direction of the haze drift |
| **Fixture shadows** | Fixtures cast shadows |
| **Grid** | Shows the ground grid |
| **Gizmos** | Shows gizmos |
| **Render scale (%)** | Render resolution |

The environment and the haze belong to the venue. They sync with the venue to your other devices. The grid, gizmos and render scale belong to this device.

## Venue Members

A venue has an owner and can have members. Venue content syncs to the owner and to each member. An owner cannot leave their own venue.
