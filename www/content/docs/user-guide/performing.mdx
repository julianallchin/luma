# Perform

Each venue has a **Perform** tab. Open it from the venue's row in the sidebar
or from the new-tab box. Closing the tab does not stop anything: Luma keeps
following the decks and keeps every value.

## Deck Sources

Luma follows one DJ source at a time. Connect it from the deck panel beside
the stage in **Live**: **Add source** lists the sources and the latency, and a
connected source can be changed or disconnected from the same place, which
puts the set back on the tapped tempo.

| Source | Hardware | Notes |
|--------|----------|-------|
| **Rekordbox** | rekordbox on this computer | Read through [rkbx_link](https://github.com/grufkork/rkbx_link) over OSC. Turn on `osc.msg.n/time` in rkbx_link's config; it is off by default. Load tracks after Luma starts listening. |
| **Pro DJ Link** | Pioneer CDJs | To connect, Luma claims a virtual player number. That number must not be the number of a real deck on the network. |
| **StageLinQ** | Denon DJ / Engine DJ | Luma listens for devices and reads deck telemetry. |

Luma matches the track each deck loads against the library and plays that
track's scores for the venue. Each deck renders its own layer at its own time,
and the layers blend by deck volume. Between reports from the source, Luma
runs each deck's clock forward, so the lights keep moving.

Without DJ gear, pick a library song to play on the tab's **virtual deck**: the
app's own player becomes deck 1.

## The Perform set

Beside the decks, each venue has a set of live patterns. A pattern is a clip
graph with no timeline: a selection, a blend mode and a graph. The set is laid
out on pages of a grid, like a console's executor window. A cell holds a
pattern, the master, tap tempo, or a fader that moves several things together.

- A pattern's **pad** is a `button` node wired into its output's alpha. It plays
  as **toggle** (on until the next press) or **flash** (on while held), and
  fades with its own attack, decay, sustain and release.
- A `control` node is a fader of that pattern, shown in its cell.
- Every pattern plays at its level times the Perform master, over the decks.
- In a page's one-at-a-time rows, turning one pattern on releases the others.

The Perform tab has its own chat. Ask it to add, change or lay out patterns.

## MIDI and OSC

Any MIDI device and anything that sends OSC (to UDP port 8000) can drive a fader
or a pad. Press **Learn** on a control, then move the fader or press the key.
A binding says what the hardware sends: a fader's position, a pad's press and
release, or a latching key. It can be inverted. Bindings belong to a
controller, and sync with the venue.

A controller with a profile knows where its pads and faders sit, and its pad
lights show what each control does. **Map this page** puts the page's cells on
its grid. Luma ships no profiles: press **Set up with the agent** in Edit
layout, and the Perform chat writes one with you, lighting pads one at a time
and asking what you see. Click the controller's name to rename it.

## Art-Net Output

Luma sends DMX over Art-Net on UDP port 6454. Settings are in **Settings → Art-Net / DMX**:

| Setting | Meaning |
|---------|---------|
| **Enable Art-Net Output** | Turns Art-Net output on or off |
| **Always Broadcast (255.255.255.255)** | Sends to the broadcast address |
| **Interface IP (Bind Address)** | The address to bind. `0.0.0.0` binds to all interfaces. |
| **Unicast Destination IP** | A single destination. Empty means broadcast only. |
| **Net / Subnet** | The Art-Net net and subnet |

The page also has a brightness limit for all DMX output. 100 means no limit.

The text fields and node discovery cannot be edited in the native app yet.

You need an Art-Net node on the same network. The node receives the Art-Net packets and sends DMX-512 to the fixtures.

## From Values to DMX

1. Luma evaluates the active clips and [combines them](/docs/user-guide/annotations#how-clips-combine) into one `UniverseState`.
2. It maps each head's dimmer, color, strobe, position and speed to the DMX channels of the fixture's mode.
3. It writes one DMX buffer for each universe and sends it over Art-Net.
