# Perform

<Callout type="warn">
Perform is not yet available in the native app. The backend for live performance exists. The native Perform view will come in a later version.
</Callout>

This page describes the perform backend and the Art-Net output that is available now.

## Deck Sources

The backend reads deck state from two protocols. Both can run at the same time as a MIDI mixer.

| Source | Hardware | Notes |
|--------|----------|-------|
| **StageLinQ** | Denon DJ / Engine DJ | Luma listens for devices and reads deck telemetry. |
| **Pro DJ Link** | Pioneer CDJs | Discovery listens for CDJ keepalives for 3 seconds. To connect, Luma claims a virtual player number. That number must not be the number of a real deck on the network. |

The backend matches the track that a deck loads against the library.

## MIDI

- **Mixer.** A MIDI connection to a DJ mixer (for example DJM, Xone or Rane). Luma maps its CC messages to channel faders and the crossfader.
- **Controller.** A MIDI controller. Its bindings set group intensity and turn the controller layer on and off.

In perform mode, the render engine renders one layer for each deck and blends the layers by volume.

## Art-Net Output

Luma sends DMX over Art-Net on UDP port 6454. Settings are in **Settings → Art-Net / DMX**:

| Setting | Meaning |
|---------|---------|
| **Enable Art-Net Output** | Turns Art-Net output on or off |
| **Always Broadcast (255.255.255.255)** | Sends to the broadcast address |
| **Interface IP (Bind Address)** | The address to bind. `0.0.0.0` binds to all interfaces. |
| **Unicast Destination IP** | A single destination. Empty means broadcast only. |
| **Net / Subnet** | The Art-Net net and subnet |

The page also has a brightness limit for all DMX output. 100 means no limit.

The text fields and node discovery cannot be edited in the native app yet.

You need an Art-Net node on the same network. The node receives the Art-Net packets and sends DMX-512 to the fixtures.

## From Values to DMX

1. Luma evaluates the active clips and [combines them](/docs/user-guide/annotations#how-clips-combine) into one `UniverseState`.
2. It maps each head's dimmer, color, strobe, position and speed to the DMX channels of the fixture's mode.
3. It writes one DMX buffer for each universe and sends it over Art-Net.
