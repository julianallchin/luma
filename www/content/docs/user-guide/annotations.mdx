# Place Clips

The track editor shows one track on a timeline. You place patterns on the timeline as **clips**. The clips of one track in one venue make a **score**.

## Scores

A score belongs to one track and one venue. A track can have many scores. The score list shows each score with its venue, its author, its clip count and its age. Use **New score** to start a new score.

A score that another user wrote opens in read-only mode. You can view it, but you cannot change it.

## Add a Clip

1. Click **Add pattern**. A searchable pattern picker opens.
2. The picker shows a looping preview of the pattern on the current venue.
3. Choose a pattern. Luma adds it to the timeline as a clip.

See [Forms and Presets](/docs/user-guide/patterns).

## Clip Properties

| Property | Description |
|----------|-------------|
| **Form** | The form that the clip plays. |
| **Start** | Where the clip begins, in beats. |
| **Duration** | How long the clip lasts, in beats. |
| **Z index** | The stacking order. A clip with a higher z index is placed above a clip with a lower z index. |
| **Blend mode** | How the clip combines with the clips below it. The default is `replace`. |
| **Selection** | A [selection expression](/docs/user-guide/groups-and-tags#selection-expressions). The default is `all`. |
| **Inputs** | A value for every input of the form, such as color, width or every. |
| **Seed** | The seed for random choices in the form. |

The clip inspector shows the blend mode and the form's inputs. It sorts known inputs under the headings **Shape**, **Space**, **Timing** and **Appearance**.

**Pick fixtures** opens a dialog. It lists the venue's groups next to a picture of the venue. Tick groups to write a union such as `front_wash | back_movers`. The dialog cannot write `&`, `~` or `^`. If the current expression uses them, the dialog shows it as read-only text.

## How Clips Combine

Luma evaluates the score for each frame. It takes the clips that are active at that time and folds them from the lowest z index to the highest.

For each head:

- **The first clip** that lights a head sets its values directly.
- **Each later clip** blends onto the result with its blend mode.
- **Only the capabilities that a clip drives** take part. A clip that drives only color does not change dimmer, strobe, position or speed.
- **Color** blends with the top clip's dimmer as its opacity. A dark clip changes the color less than a bright clip.
- **Dimmer and strobe** blend with the blend mode.
- **Position** is taken from the top clip.
- **Speed** is taken from the top clip and is 0 or 1.

The nine blend modes and their formulas are in the [blend mode table](/docs/architecture/compositor#blend-modes).
