## Frequency energy

`band_energy` · Built-in kernel

The energy of the full mix between Low frequency and High frequency.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `high_hz` | High frequency (Hz) | Signal (number, one channel) | fixed | `60` |  |
| `low_hz` | Low frequency (Hz) | Signal (number, one channel) | fixed | `20` |  |

| Output | Type | Rate |
|---|---|---|
