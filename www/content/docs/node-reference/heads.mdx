A shaper changes the heads that the nodes after it see. Its output goes into another node's `heads` input. Shapers stack: wire one shaper's output into the next one's `heads`. An empty `heads` input is all the clip's heads.

The heads wire carries, for each unit: its member heads, a position (moved by mirrors), a span, and a shuffled rank after a shuffle.

## Mirror

`mirror` · Python: `mirror(heads, direction, at)` · Gives heads.

Folds the heads across a plane, as a shader's reflect. The plane is across `direction`, at `at` along it within the selection before any fold, so 0.5 is always the middle. Heads on the low side take their reflected position, and aim yaw and pitch are mirrored for them. Mirrors stack: two mirrors give four-fold symmetry. A mirror moves heads, never a space's ruler.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the clip's heads. |
| `direction` | vector | u, v, z | not zero | a value, or a wire over time | Best fit: the stage axis the heads spread along most. |
| `at` | number | share | 0–1 | a value, or a wire over time | 0.5, the middle. |

## Shuffle

`shuffle` · Python: `shuffle(heads, time)` · Gives heads.

A random order of the heads within each span. Read it with `space(kind="order")`. With a `time` wire from a time node with `every` or `on`, the order is new for each event: each press, for a press clock. Positions do not change. Heads a mirror folded together share one place in the order, whether the mirror comes before or after the shuffle.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the clip's heads. |
| `time` | time |  |  | a wire | One order for the whole clip. |

## Group

`group` · Python: `group(heads, size)` · Gives heads.

Merges heads into units of `size` consecutive heads within a fixture, in head number order. A unit acts as one head: one position (the centre of its heads), one rank, one random value.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the clip's heads. |
| `size` | number | heads | 1 or more | a value, or a wire over time | One fixture: all the heads of a fixture are one unit. |

## Split

`split` · Python: `split(heads, by="fixture")` · Gives heads.

Makes each fixture, or each venue group of the selection, its own span. A space measures its ruler inside each span, a shuffle shuffles inside each span, and a mirror folds inside each span.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the clip's heads. |

| Setting | Options | Default | Notes |
|---|---|---|---|
| `by` | `fixture`, `group` | `fixture` |  |
