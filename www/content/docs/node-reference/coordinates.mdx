A coordinate node gives a raw coordinate at each head, usually 0–1. A coordinate is not a value: wire it into a curve's `x`, and the curve turns it into a number, vector or color. `brightness=time()` is an error; `brightness=curve(time(), "Ramp up")` is right.

## Time

`time` · Python: `time(every, duration, delay, phase)` · Gives a coordinate.

Each head's own clock: 0–1 over the clip, or 0–1 over each event. With `every`, an event starts every `every` beats from the clip start. Each head's clock is the event's age over its duration, minus `delay / duration`. When `phase` is set, the clock wraps: `fract(clock + phase / 360)`, so 360° is one event. Before a head starts, its clock is below 0 and a curve holds its first value; after it ends, the curve holds its last value. A curve over space on `delay` makes a one-shot (a wipe); on `phase` it makes a loop (a chase, a wave). Two time nodes with equal `every` and `duration` share one set of events.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `every` | number | beats | above 0 | a value or a wire | Once over the clip: no events. |
| `duration` | number | beats | above 0 | a value or a wire | `every`; with no `every`, the clip's length. A `duration` with no `every` is one event of that length from the clip start. |
| `delay` | number | beats | any | a value or a wire | 0. |
| `phase` | number | degrees | any | a value or a wire | No phase: the clock does not wrap. |

- A number in `every`, `duration` and `delay` is on the beat grid: a multiple of 1/32 or 1/24 of a beat. The editor snaps a typed number to it. A wire is free.
- `every` and `duration` set a clock's period. A wire that follows events gives them the newest event's value, so the clock keeps its own events.

## Space

`space` · Python: `space(heads, direction, centre, at, shift, scale, kind="line", wrap)` · Gives a coordinate.

Each head's place on a ruler across the clip's selection, or across each span after a split. The ruler `a` runs 0–1 by `kind`. The output is `x = at + (a − at − shift) / scale`; with `wrap`, `x = fract(x)` and the shape repeats every `scale` (0.25 is four copies). As in CSS: `at` is the transform origin, `shift` the translate, `scale` the scale, and wrap is background-repeat. The ruler is measured on the selection before any mirror: a mirror moves heads along it, never the ruler. A curve over time on `shift` moves a shape along the heads (a chase); audio on `shift` makes a meter. A region is a curve with jumps: `curve(space(), [[0, 1], [0.5, 1], [0.5, 0], [1, 0]])` is the left half.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the clip's heads. |
| `direction` | vector | u, v, z | not zero | a value, or a wire over time | Best fit. For `line` and `order`: the stage axis the heads spread along most (U, then V, then Z on ties). For `radial` and `angle`: the direction the heads spread along least. |
| `centre` | vector | share | 0–1 each | a value, or a wire over time | (0.5, 0.5, 0.5), the middle of the selection's box. Only `radial` and `angle` read it. |
| `at` | number | share | 0–1 | a value or a wire | 0. |
| `shift` | number | share | any | a value or a wire | 0. |
| `scale` | number | share | 0 or more | a value or a wire | 1. |

| Setting | Options | Default | Notes |
|---|---|---|---|
| `kind` | `line`, `order`, `radial`, `angle` | `line` | `line`: the head's position along `direction`, lowest head 0, highest 1. `order`: the heads sorted along `direction`; heads at one place share a slot, and each reads (slot + 0.5) / slots; after a shuffle, each head reads a random slot. `radial`: the distance from `centre` over the largest distance, in the plane across `direction`. `angle`: turns around `centre` in that plane. |
| `wrap` | `no`, `yes` | `no` | `yes` tiles the output. A node with no `wrap` stored reads `yes` for `angle` and `no` for the other kinds. |

## Along

`along` · Python: `along()` · Gives a coordinate.

The place within a laser element, 0–1: from a line's start to its end, or once round a ring or polygon. A beam is one point, at 0. Only a figure's `x`, `y`, `size`, `rotation` and `color` read it, through curves and math. Each line, ring or polygon is evaluated at 32 places along it. Black along an element is the light off, so a shape with jumps to 0 makes dashes.

No inputs.

## Random

`random` · Python: `random(heads, every, glide, scale, contrast)` · Gives a coordinate.

A random value, 0–1 at each head, drawn again each turn of `every` beats. Random gives a value; Shuffle gives an order. `glide` 0 jumps to the new value on the turn and holds it; 1 drifts the whole turn; in between, it holds for the first 1 − glide of the turn and then eases to the next value. `scale` is how far apart heads are before their values differ, as a share of the heads' largest extent: 0.02 gives each head its own value. Heads a mirror folded together read one value. `contrast` spreads the values away from 0.5, up to four times at 1, and clips them to 0–1. Each random node has its own stream, from the clip's seed and the node's id.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the clip's heads. |
| `every` | number | beats | above 0 | a value or a wire | 4 beats. |
| `glide` | number | share | 0–1 | a value or a wire | 0. |
| `scale` | number | share | above 0 | a value or a wire | Uniform: one value for all heads. |
| `contrast` | number | share | 0–1 | a value or a wire | 0. |

- `every` sets a clock's period. A wire that follows events gives it the newest event's value, so the clock keeps its own events.

## Audio

`audio` · Python: `audio(low_hz, high_hz), or audio("low")` · Gives a coordinate.

The energy of a frequency band of the track's full mix, 0–1 over the whole track. Every clip on a track reads the same level at the same moment. Threshold, floor and gain belong in the curve that reads it. `high_hz` must be above `low_hz`. In Python a band name gives both edges; the bands are `sub` (20–60 Hz), `low` (60–300 Hz), `mid` (300–4000 Hz), `high` (4000–20000 Hz).

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `low_hz` | number | Hz | 20–20000 | a value, or a wire over time | 60 Hz, the low band. |
| `high_hz` | number | Hz | 20–20000 | a value, or a wire over time | 300 Hz, the low band. |

## Fader

`control` · Python: `control(name="fader")` · Gives a coordinate.

A fader: a live value 0–1, the same at every head, that a performer moves. A curve maps it to the range an input needs, so one fader can drive many inputs, each with its own range. In a Perform pattern it is a fader of that pattern, shown in the pattern's cell. In a score it reads the venue's live control called `name`; a control nothing has set reads 0. A fader cannot reach a clock input (`every`, `duration`) or a fixed input: those are prepared before the clip plays. Moving a fader never prepares the graph again.

No inputs.

| Setting | Options | Default | Notes |
|---|---|---|---|
| `name` | text | `fader` | A control name in snake_case, at most 64 characters, such as `drop` or `front_level`. |

## Button

`button` · Python: `button(name="button", mode="flash", attack=0, decay=0, sustain=1, release=0, unit="beats", shape="smooth")` · Gives a coordinate.

A button a performer presses: 0–1 along its envelope, the same at every head. In `flash` mode it is on while held; in `toggle` mode, from one press to the next. The value rises over the attack, falls to the sustain over the decay, holds while on, and falls to 0 over the release. In a Perform pattern, the button that the output's `alpha` depends on is the pattern's pad. In a score a button reads the venue's control `name` as a plain gate, and its envelope does not apply. Like a fader, it cannot reach a clock input or a fixed input.

No inputs.

| Setting | Options | Default | Notes |
|---|---|---|---|
| `name` | text | `button` | A control name, as for a fader. |
| `mode` | `flash`, `toggle` | `flash` |  |
| `attack` | a number | `0` | A length of 0 or more, in `unit`. |
| `decay` | a number | `0` | A length of 0 or more, in `unit`. |
| `sustain` | a number | `1` | A level, 0–1. |
| `release` | a number | `0` | A length of 0 or more, in `unit`. |
| `unit` | `beats`, `seconds` | `beats` | Beats are counted at the tempo the Perform set plays at. |
| `shape` | `smooth`, `linear`, `punchy`, `snap` | `smooth` | The shape of each stage of the envelope. |
