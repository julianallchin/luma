Colors are normalized RGB from 0 to 1. Gradients interpolate in the OKLab color space.

## Sample gradient

`sample_gradient` · Built-in kernel · Placeable as a clip

The color and opacity of a gradient at Position.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `gradient` | Gradient | Gradient | per frame | `RGB (0, 0, 0) at 0, RGB (1, 1, 1) at 1` |  |
| `position` | Position | Signal (0–1, one channel) | per frame | `0` |  |

| Output | Type | Rate |
|---|---|---|
| `color` | Signal (0–1, RGB) | per frame |
| `opacity` | Signal (0–1, one channel) | per frame |

## Mix palette

`mix_palette` · Built-in kernel · Placeable as a clip

Mixes the colors of a palette by channel weights. Gives a color and an opacity.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `gradient` | Gradient | Gradient | per frame | `RGB (0, 0, 0) at 0, RGB (1, 1, 1) at 1` |  |
| `perceptual` | Perceptual mix | Boolean | fixed | `off` |  |
| `vibrance` | Vibrance | Signal (number, one channel) | per frame | `0.6` |  |
| `weights` | Color weights | Signal (number, any channels) | per frame | required |  |

| Output | Type | Rate |
|---|---|---|
| `color` | Signal (0–1, RGB) | per frame |
| `opacity` | Signal (0–1, one channel) | per frame |
