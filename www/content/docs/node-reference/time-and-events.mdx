These nodes read musical time and produce events. An event stream is a value of type Events. Nodes such as Pulse, Chase and Dissolve start one response for each event.

## Clip time

`clip_time` · Built-in kernel

Musical time inside the clip: beats since the clip start, progress from 0 to 1, the clip duration in beats and the absolute beat.

No inputs.

| Output | Type | Rate |
|---|---|---|
| `beat` | Signal (number, one channel) | per frame |
| `duration` | Signal (beats, one channel) | per frame |
| `elapsed` | Signal (beats, one channel) | per frame |
| `progress` | Signal (0–1, one channel) | per frame |

## Rhythm

`rhythm` · Built-in kernel

A repeating clock. `elapsed` is the beats since the current stroke started. `cycle` is the number of the current stroke, counted from the origin.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `delay` | Phase delay | Signal (beats, one channel) | fixed | `0 beats` | Shift stroke starts later on the beat grid |
| `grid_aligned` | Follow track grid | Boolean | fixed | `off` | Otherwise start at the clip boundary |
| `repeat` | Repeat | Signal (beats, one channel) | fixed | `4 beats` | Time between stroke starts, in beats |

| Output | Type | Rate |
|---|---|---|
| `cycle` | Signal (number, one channel) | per frame |
| `elapsed` | Signal (beats, one channel) | per frame |

## Beat trigger

`beat_trigger` · Built-in kernel

## Random subset

`random_subset` · Built-in kernel

Gives each event a seeded random set of target heads. Proportion sets the fraction of heads. Shuffled cycle walks through a shuffled order to reduce overlap between consecutive events.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `cycle` | Shuffled cycle | Boolean | fixed | `off` | Cycle through a seeded shuffled order. Minimizes consecutive overlap when the eligible selection stays the same. |
| `events` | Events | Events | fixed | `every 1 beats` |  |
| `proportion` | Proportion | Signal (0–1, one channel) | fixed | `0.25` |  |
| `seed` | Seed | Seed | fixed | `0` |  |

| Output | Type | Rate |
|---|---|---|
| `events` | Events | fixed |
