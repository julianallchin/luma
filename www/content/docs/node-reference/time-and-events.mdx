These nodes read musical time. A form counts its events with Event life and reads curves with Curve.

## Clip time

`clip_time` · Built-in kernel

Musical time inside the clip: beats since the clip start, progress from 0 to 1, the clip duration in beats and the absolute beat.

No inputs.

| Output | Type | Rate |
|---|---|---|
| `beat` | Signal (number, one channel) | per frame |
| `duration` | Signal (beats, one channel) | per frame |
| `elapsed` | Signal (beats, one channel) | per frame |
| `progress` | Signal (0–1, one channel) | per frame |

## Odometer

`core/odometer` · Built-in kernel

Turns counted since the clip start, one turn every Period beats. A period curve changes the period over the clip without a jump.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `period` | Period | Signal (beats, one channel) | fixed | `4 beats` | Beats for one turn; zero means the whole clip |
| `period_curve` | Period curve | Time | fixed | required | Period over the clip, in beats |

| Output | Type | Rate |
|---|---|---|
| `turns` | Signal (number, one channel) | per frame |

## Event life

`core/event_life` · Built-in kernel

One event every Every beats. Gives the progress of the current event through its Life, from 0 to 1, and the event index.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `every` | Every | Signal (beats, one channel) | fixed | `4 beats` | Beats between events; zero means one event over the clip |
| `every_curve` | Every curve | Time | fixed | required | Beats between events, over the clip |
| `life` | Life | Signal (beats, one channel) | fixed | `2 beats` | Beats one event lasts; zero means the whole clip |
| `life_curve` | Life curve | Time | fixed | required | Beats one event lasts, over the clip |

| Output | Type | Rate |
|---|---|---|
| `index` | Signal (number, any channels) | per frame |
| `present` | Signal (0–1, any channels) | per frame |
| `progress` | Signal (0–1, any channels) | per frame |
| `spacing` | Signal (number, any channels) | per frame |
