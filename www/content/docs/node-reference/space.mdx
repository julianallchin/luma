A head is one independently controllable cell of a fixture. These nodes give values per head. Stage coordinates are U (stage right), V (downstage) and Z (up).

## Resolve Mapping

`resolve_mapping` · Built-in kernel

Resolves a mapping to one coordinate from 0 to 1 per head. The mapping sets the source direction, grouping, reversal and an optional mirror plane.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `mapping` | Mapping | Mapping | fixed | `source z` | Coordinate source, grouping, and orientation |

| Output | Type | Rate |
|---|---|---|
| `coordinates` | Coordinates | fixed |

## Coordinate offset

`coordinate_offset` · Built-in kernel

The distance of each head's mapped coordinate from Position. When the boundary wraps, the distance wraps into the range −0.5 to 0.5. `wrapped` is 1 for heads that wrap.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `boundary` | Boundary | Boundary | fixed | `natural` | Use mapping topology, clip, or wrap |
| `mapping` | Mapping | Coordinates | fixed | required | Resolved coordinates of independently controllable cells |
| `position` | Position | Signal (position, any channels) | per frame | `0` | Center in mapped coordinates |

| Output | Type | Rate |
|---|---|---|
| `value` | Signal (number, any channels) | per frame |
| `wrapped` | Signal (0–1, one channel) | per frame |
