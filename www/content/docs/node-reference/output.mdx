Apply is the only node that writes lighting. Every clip graph ends in one Apply.

## Apply

`output` · Built-in kernel

Writes color, pan, tilt, strobe and movement speed for each head. An unwired input leaves that capability untouched. The brightness of a head is its largest RGB channel. Apply sends it as the dimmer and normalizes the color.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `aim` | Aim | Signal (number, 3 channels) | per frame | `—` | Where the head points in U, V, Z. The vector's length, at most 1, is its weight over the aim under it |
| `color` | Color | Signal (0–1, RGB) | per frame | `RGB (1, 1, 1)` | Unwired leaves this capability untouched |
| `pan` | Pan (degrees) | Signal (degrees, one channel) | per frame | `0°` | Unwired leaves this capability untouched |
| `speed` | Movement speed | Signal (0–1, one channel) | per frame | `1` | Unwired leaves this capability untouched |
| `strobe` | Strobe | Signal (0–1, one channel) | per frame | `0` | Unwired leaves this capability untouched |
| `tilt` | Tilt (degrees) | Signal (degrees, one channel) | per frame | `0°` | Unwired leaves this capability untouched |

| Output | Type | Rate |
|---|---|---|
| `lighting` | Lighting | per frame |
