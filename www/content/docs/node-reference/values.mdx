A value node gives a number, a vector or a color. A number, vector or color input takes a value of its own type or a wire from one of these nodes. A curve is the only node that turns a coordinate into a value.

## Curve

`curve` · Python: `curve(x, shape, low, high, gradient)` · Gives a value: a number, a vector or a color.

The only node that turns a coordinate into a value. It reads `v = shape(x)`. A number or vector curve gives `low + v × (high − low)`, per component. A color curve gives `gradient(v)`. Below x 0 and above x 1 the shape holds its end values. At a jump (two points at one x), x reads the value after it. `low` and `high` take wires, so curves add: `curve(s, "Ramp up", low=a, high=a + 1)` is `a + s`. In Python the kind follows the arguments: a gradient makes a color curve, a tuple `low` or `high` a vector curve, anything else a number curve.

A shape is 2–256 points `[x, v]` or `[x, v, ease]`, x from 0 to 1 in order and v 0–1. An ease is `linear`, `sine-in`, `sine-out`, `sine-in-out`, `ease-in`, `ease-out`, `ease-in-out`, `hold`, or a Bézier `[x1, y1, x2, y2]` with x1 and x2 in 0–1. The last point has no ease. A gradient has 1–64 stops and blends in OKLab. In Python a shape or a gradient can be a preset name, such as `"Ramp up"` or `"Fire"`.

## Math

`math` · Python: `a * b, a + b, a - b, max(a, b), min(a, b)` · Gives a value: a number, a vector or a color.

Combines two or more numbers and value wires. `*`, `+`, `max` and `min` take two or more items; `-` takes exactly two (`a − b`). A number broadcasts over a vector or a color: a number times a color is a color. The output is the widest kind among the items (color, then vector, then number); a color with a vector is an error. A math result wires like a curve. In Python, math is operators on values, and a chain of one operator is one node: `cut * bloom * fade`.

## Value

`value` · Python: `value(x)` · Gives a value: a number, a vector or a color.

A named constant: a number, or three numbers. Wire one value into every input that means the same quantity, so one edit changes them all. Its type (number, vector or color) and unit are those of the inputs it feeds; inputs of two types or two units are an error. In Python, `d = value((0.57, 0, 0.82))`; a plain number stays a plain number. Deleting a value node in the editor writes its value back into the inputs it fed.
