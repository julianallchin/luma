An aim is a direction per head in stage U, V, Z. The aim form builds one from these steps.

## Aim base

`core/aim_base` · Built-in kernel

The starting aim: a direction, or the direction from each head to a point.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `base` | Base | Choice | fixed | `—` | direction or point |
| `direction` | Direction | Signal (number, 3 channels) | per frame | `—` | The aim when base is direction |
| `point` | Point | Signal (number, 3 channels) | per frame | `—` | U, V, Z in metres that every head points at when base is point |

| Output | Type | Rate |
|---|---|---|
| `direction` | Signal (number, 3 channels) | per frame |

## Aim motion

`core/aim_motion` · Built-in kernel

Moves each aim along a shape. Spread sets the phase difference across the axis. Size sets the size in degrees.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `axis` | Axis | Mapping | fixed | `source order` | How the heads are laid out |
| `cycles` | Cycles | Signal (number, any channels) | per frame | `0` | Shape cycles counted since the clip start |
| `motion` | Motion | Choice | fixed | `—` | none, shape or noise |
| `shape` | Shape | Choice | fixed | `—` | swing_left_right, swing_up_down, circle or figure_8 |
| `size` | Size | Signal (number, any channels) | per frame | `0` | Degrees |
| `spread` | Spread | Signal (number, any channels) | per frame | `0` | Degrees of phase across the axis; 360 is one cycle |
| `wander` | Wander | Signal (number, any channels) | per frame | `0` | Noise steps counted since the clip start |

| Output | Type | Rate |
|---|---|---|
| `pitch` | Signal (number, any channels) | per frame |
| `yaw` | Signal (number, any channels) | per frame |

## Aim turn

`core/aim_turn` · Built-in kernel

The fan's lean and the motion's left/right and up/down per head, with Alpha, for an Offset clip. The compositor turns the aim under the clip by it.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `alpha` | Alpha | Signal (0–1, any channels) | per frame | `1` | The share of every angle that applies |
| `axis` | Axis | Mapping | fixed | `source order` | How the heads are laid out |
| `fan` | Fan | Signal (number, any channels) | per frame | `0` | Degrees |
| `pitch` | Up/down | Signal (number, any channels) | per frame | `0` | Degrees toward the up of the aim |
| `yaw` | Left/right | Signal (number, any channels) | per frame | `0` | Degrees toward the right of the aim |

| Output | Type | Rate |
|---|---|---|
