Every clip owns one small graph. A graph has 1 to 64 nodes of 19 kinds. Exactly one node is the output: `color`, `aim`, `strobe`, `laser`. Every node has one output wire, and a wire goes into an input of another node. Every node must feed the output, directly or through other nodes. The stored graph is JSON, version 3.

To build and edit graphs in the app, see [Clips and Presets](/docs/user-guide/patterns).

## Inputs and settings

An input holds a value, a wire from another node, or nothing. Nothing is the only default: each node's table says what an empty input means. A choice, such as a space's `kind`, is a setting. A setting is never wired.

The **Takes** column says what an input accepts:

| Takes | Meaning |
|---|---|
| a value or a wire | A value of the input's type, or a wire from a node that gives that type. |
| a value, or a wire over time | The same, but the wire must be the same at every head: a value or a curve over time. |
| a value | A value only: a curve shape, a gradient, or a value node's constant. |
| a wire | A wire only. |
| a whole number | A whole number that holds for the whole clip, and no wire. |

## Types

| Type | A value is |
|---|---|
| number | One number, in the input's unit. |
| vector | Three numbers `(u, v, z)`: a direction, a point in the selection, or metres. |
| color | Three numbers `(r, g, b)`, linear Rec. 2020, each 0–1. |
| points | A curve shape: points `[x, v]` or `[x, v, ease]`. See [Curve](/docs/node-reference/values#curve). |
| gradient | Color stops from 0 to 1. |
| values | A math node's items: numbers and value wires. |
| coordinate, heads, time, figures | Wires only; see [Wires](#wires). |

## Units

| Unit | Meaning |
|---|---|
| share | A share of something, 0–1 unless the range says otherwise. The editor shows a share as a percent. |
| beats | Beats of the track, or of the Perform set's tempo. |
| degrees | Aim angles and rotations. A time node's phase is in degrees too: 360° is one event. |
| metres | A place in the venue: +U stage right, +V toward the crowd, +Z up. |
| Hz | A frequency of the track's audio. |
| u, v, z | A direction on the stage, in the venue's axes. Only its way counts, never its length, and it is never zero. |
| RGB | A color. |
| heads | A count of heads or elements. |

Positions in the selection are shares too. A **selection number** (`space.at`, `mirror.at`) is one place 0–1 along the node's ruler. A **selection point** (`space.centre`) is `(u, v, z)`, each 0–1 of the selection's box; (0.5, 0.5, 0.5) is the middle. Both are measured on the selection before any mirror, and per span after a split. `aim.point` is the one input in metres.

## Wires

| Wire | From | Into |
|---|---|---|
| coordinate | `time`, `space`, `along`, `random`, `audio`, `control`, `button` | `curve.x` |
| value | `curve`, `math`, `value`, a color `control` | any number, vector or color input of its type, a curve's `low` and `high`, a math node's `values` |
| heads | `mirror`, `shuffle`, `group`, `split` | `space.heads`, `random.heads`, `mirror.heads`, `shuffle.heads`, `group.heads`, `split.heads`, `figure.heads`, `aim.heads` |
| time | `time` | `shuffle.time` |
| figure | `figure` | `laser.figures` |

## Python

Agents write clip graphs as Python (`backend/python/luma_exec/clip.py`). Each kind has a builder of its own name, except `math`, which is Python operators on values. A node's id is the variable it is assigned to, so the code, the graph and the card in the editor use the same name. The Rust checker checks the graph when an agent adds or updates a clip.

```python
t = time(every=2)
place = space(shift=curve(t, "Ramp up", low=-0.2, high=1), scale=0.2)
graph = color(brightness=curve(place, [[0, 0], [0, 1], [1, 1], [1, 0]]))
```
