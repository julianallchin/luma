A graph has exactly one output node. The output decides what the clip does to the lights and which blend modes the clip can use. The blend mode is on the clip, not on the node. Laser output is on [its own page](/docs/node-reference/lasers).

**Brightness 0 is black light. Alpha 0 is no clip.** A head at brightness 0 is lit black: in Replace it covers the light below with black. A head at alpha 0 is not there, and the light below shows, in every blend mode. Between a clock's events, and outside the clip, the clip is at alpha 0.

When a clock's events overlap, they make one layer. Color and strobe keep the largest value per channel across the live events. Aim lays the newest event over the older ones by its alpha.

## Color

`color` · Python: `color(color, brightness, alpha)` · Gives nothing: it is the clip's output. Blend modes: Replace, Add, Multiply, Screen, Max, Min, Subtract.

The light of each head: color × brightness. `brightness` is the pattern across the lights: a chase, a pulse, a cut. `alpha` is the clip's opacity: the clip's light blends with the light below by the blend mode, and the result mixes with the light below by alpha. The timeline's fade handles edit `alpha`. Colors are linear Rec. 2020.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `color` | color | RGB | 0–1 each | a value or a wire | White, (1, 1, 1). |
| `brightness` | number | share | 0–1 | a value or a wire | 1. |
| `alpha` | number | share | 0–1 | a value or a wire | 1. |

## Aim

`aim` · Python: `aim(heads, base="direction", direction, point, yaw, pitch, alpha)` · Gives nothing: it is the clip's output. Blend modes: Replace, Offset.

Points moving heads. `base` picks the starting aim: `direction` aims along the vector, `point` aims each head at the point, `away` aims each head from the point through the head (a fan that spreads). Then `yaw` and `pitch` turn the aim: positive yaw turns counter-clockwise seen from above, positive pitch turns up. Heads that a mirror folded take the mirror image of yaw and pitch. `point` is in metres in the venue: +U stage right, +V toward the crowd, +Z up; `direction` uses the same axes. `alpha` is the aim's weight. In Replace, the heads turn toward this aim by `alpha`. In Offset, the base is not used: `yaw` and `pitch`, times `alpha`, turn the aim of the clips below, so one movement clip can run over many positions.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the clip's heads. |
| `direction` | vector | u, v, z | not zero | a value or a wire | (0, 0.766, −0.643): toward the crowd and down. |
| `point` | vector | metres | any | a value or a wire | (0, 0, 0). |
| `yaw` | number | degrees | −180 to 180 | a value or a wire | 0. |
| `pitch` | number | degrees | −180 to 180 | a value or a wire | 0. |
| `alpha` | number | share | 0–1 | a value or a wire | 1. |

| Setting | Options | Default | Notes |
|---|---|---|---|
| `base` | `direction`, `point`, `away` | `direction` | The editor shows only the vector the base uses. |

## Strobe

`strobe` · Python: `strobe(rate, alpha)` · Gives nothing: it is the clip's output. Blend modes: Replace, Add, Multiply, Screen, Max, Min, Subtract.

Strobes the fixtures' shutters at `rate`. `alpha` is the clip's opacity over the strobe below.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `rate` | number | share | 0–1 | a value or a wire | 0.5. |
| `alpha` | number | share | 0–1 | a value or a wire | 1. |
