A laser clip draws on ILDA projectors. Its output is a `laser` node, which draws a list of `figure` nodes in order on each projector in the clip's selection: `laser([sheet, rails, dots])`.

Each figure draws `count` elements: beams, lines, rings, polygons or grid points. The elements are the figure's heads. Space, Random, Shuffle and Mirror read a figure's elements as they read a moving head's heads, apart from any other figure's elements.

A figure draws on the zone's canvas, which runs from −1 to 1 across and up the zone. The same place on the canvas is the same direction from every projector. A projector draws at most 64 elements, all its figures together.

A laser's color is its figures' color, and the color is its power: black is the light off. Color clips do not reach projectors. A laser clip blends by Replace (it morphs the elements under it into its own) or Add (it draws both).

## Figure

`figure` · Python: `figure(kind="beams", count, sides, x, y, size, rotation, color, heads)` · Gives a figure, for a laser's `figures`.

A laser figure: `count` elements on each projector in the clip's selection. Wire it into a laser's `figures`. Per element, `x` and `y` place its centre on the canvas, `size` is a line's half length or a ring's radius, `rotation` turns it, and `color` is its color and power. An element whose `x` or `y` is empty sits at its home place: beams in a row and a grid in rows, `size` wide and turned by `rotation`; a line, ring or polygon in the middle. Wire `along` into `x`, `y`, `size`, `rotation` or `color` to vary them within each element. Heads from a mirror draw the mirror image.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `heads` | heads |  |  | a wire | All the figure's elements. |
| `count` | number | heads | 1–64 | a whole number | 8 for `beams` and `grid`, 1 for the other kinds. |
| `sides` | number |  | 3–12 | a whole number | 3. Only `polygon` reads it. |
| `x` | number | share | −1 to 1 | a value or a wire | The element's home place. |
| `y` | number | share | −1 to 1 | a value or a wire | The element's home place. |
| `size` | number | share | 0–1 | a value or a wire | 0.5. |
| `rotation` | number | degrees | −180 to 180 | a value or a wire | 0. |
| `color` | color | RGB | 0–1 each | a value or a wire | White, (1, 1, 1). |

- `count` and `sides` shape the clip's heads, so they hold a whole number for the whole clip and take no wire.

| Setting | Options | Default | Notes |
|---|---|---|---|
| `kind` | `beams`, `line`, `ring`, `polygon`, `grid` | `beams` | `beams` and `grid` draw points; `line`, `ring` and `polygon` draw outlines. |

## Laser

`laser` · Python: `laser(figures, alpha, zone="")` · Gives nothing: it is the clip's output. Blend modes: Replace, Add.

The laser output: draws its figures, in order, on each projector in the clip's selection. A projector's elements are every figure's together, and they share its scan, so a figure added dims the others, as on a real projector. Each figure can be in the list once.

| Input | Type | Unit | Range | Takes | Empty |
|---|---|---|---|---|---|
| `figures` | figures |  |  | a list of wires | Required: one or more figure wires. |
| `alpha` | number | share | 0–1 | a value or a wire | 1. |

| Setting | Options | Default | Notes |
|---|---|---|---|
| `zone` | text | empty | A laser zone id of the venue. Empty, or an id the venue does not have, is the venue's first zone. A venue with no zone draws in a window ahead into the house. |
