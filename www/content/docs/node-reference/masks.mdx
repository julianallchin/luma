A mask is a value from 0 to 1 per head. Multiply a mask by a color to make a lit effect.

## Pulse

`pulse` · Graph of 2 nodes

For each trigger event, samples Shape over Duration beats. Overlapping events combine with the maximum.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `duration` | Duration | Signal (beats, one channel) | fixed | `2 beats` | How long each pulse lasts, in beats |
| `shape` | Shape | Envelope | per frame | `(0, 1) (1, 0)` | Brightness over each pulse |
| `trigger` | Trigger | Events | fixed | `no events` | Each event starts an independent pulse |

| Output | Type | Rate |
|---|---|---|
| `mask` | Signal (0–1, one channel) | per frame |

## Dissolve

`dissolve` · Graph of 5 nodes

Each trigger event lights a seeded random set of heads. Coverage sets the fraction of heads over the event. Brightness curve sets their level.

| Input | Name | Type | Rate | Default | Description |

| `shape` | Brightness curve | Envelope | per frame | `(0, 1) (1, 1)` | Brightness of the lit heads over each dissolve |
| `softness` | Softness | Signal (0–1, one channel) | per frame | `0` | Fraction of heads that fade partially at the coverage edge |

## Random selection
