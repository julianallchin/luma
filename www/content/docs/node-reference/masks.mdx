A mask is a value from 0 to 1 per head. Multiply a mask by a color to make a lit effect.

## Random share

`core/random_share` · Built-in kernel

A seeded random share of the heads for each event index. Coverage sets the share. Grain sets how many heads light together.

| Input | Name | Type | Rate | Default | Description |
|---|---|---|---|---|---|
| `coverage` | Coverage | Signal (0–1, any channels) | per frame | `0.5` | Share of heads lit |
| `grain` | Grain | Signal (number, one channel) | fixed | `1` | 1 is one head, 0 is one fixture, N is a clump of N heads |
| `index` | Event index | Signal (number, any channels) | per frame | `0` | Each index draws a new random set |

| Output | Type | Rate |
|---|---|---|
| `selected` | Signal (0–1, any channels) | per frame |
