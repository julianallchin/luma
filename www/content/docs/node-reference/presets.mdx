## Curve shapes

A curve's shape chip lists these. In Python, a shape can be one of these names.

`On`, `Ramp up`, `Ramp down`, `Step up`, `Step down`, `Triangle`, `Soft`, `Comet`, `Spike`, `Drop`, `Swell`, `Fade in`, `Fade out`, `Square`, `Sine`, `Cosine`, `Double sine`, `Steps 2`, `Steps 3`, `Steps 4`, `Steps 8`.

## Gradients

A color curve's gradient chip lists these. In Python, a gradient can be one of these names.

`Rainbow`, `Warm`, `Cool`, `Fire`, `Ocean`, `Sunset`, `B/W`.

## Audio bands

An `audio` node's empty band is `low`. In Python, `audio("mid")` reads a band by name.

| Band | Low | High |
|---|---|---|
| `sub` | 20 Hz | 60 Hz |
| `low` | 60 Hz | 300 Hz |
| `mid` | 300 Hz | 4000 Hz |
| `high` | 4000 Hz | 20000 Hz |
