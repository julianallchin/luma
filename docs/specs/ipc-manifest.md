`cargo test --manifest-path backend/Cargo.toml ipc_manifest` fails when it is stale and
rewrites it when run with `LUMA_UPDATE_GOLDENS=1`.

## Events

Host events are the only push channel; there is no subscription command. They are the
`Event` enum in `backend/src/events.rs`, which every host matches exhaustively.
