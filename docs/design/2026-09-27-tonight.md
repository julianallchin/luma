## 1. Wide-gamut color (yes)

- Today: colors are gamma-encoded sRGB 0–1 (`backend/crates/patterns/src/color.rs`),
  gradients blend in OKLab. sRGB cannot hold deep red, cyan, lime or royal
  blue, which LED fixtures make.
- Working space: linear Rec. 2020. OKLab stays for blending, with the
  Rec. 2020 matrix.
- Per-fixture gamut mapping at output (RGBW, RGBAL, CMY): each fixture takes
  the nearest color it can make instead of clipping.
- Picker shows wide colors on the HDR display.
- Migration: convert every saved color in scores and presets once.
- Brightness stays the peak channel, split out as the dimmer
  (`backend/crates/patterns/src/output.rs`).

## 2. Absolute and relative aim (yes)

- Aim clips blended replace-only before this work. Aim now has the clip blend
  dropdown with two options: Replace (absolute, today's behaviour) and
  Offset (relative: base ignored, fan and motion turn the aim under the
  clip, alpha scales the degrees, over no aim it starts from home). Layers
  apply bottom to top, so one movement clip can run over many positions.
- Target look: an animated move on one layer with a pinwheel stacked on it
  in Offset.

## 3. One Color form with Space as a source (yes)

- Add `Space` to the input sources (`src/sources.rs`): Time, Hit, Noise,
  Audio, Space.
- A Space source is the axis row (source, span, mirror, plane) plus a
  gradient or curve across 0–1.
- It has an offset input that can take Time. A moving offset is a chase.
- Color and brightness inputs can take Space.
- Merge `color.constant`, `color.time`, `color.space` and `color.chase` into
  one `color@1` form.
- Rewrite their presets as saved inputs of `color@1`.
- Migrate saved clips from the old form ids; check old and new output match.
- UI: the source picker on each input shows Space.
- UI: one curve strip for number and color inputs. Keep the current
  envelope editor (`gpui/crates/ui/src/arg/envelope.rs`) as the base. A color
  input uses the same editor with stops that move in x only and a gradient
  fill.
- On Time: beat grid lines behind the graph (bars stronger) and the
  playhead at the current phase of the cycle. The editor has neither today.
- On Space: one tick per head, colored with the value that head gets.
- Open: whether sparkle and noise fold in too.

## 4. Proposed, not approved

- **2D plane coordinates.** Each head gets (x, y) in metres in an
  `AxisPlane`. Base for shapes and a 2D fan.
- **Shapes as distance fields.** Line, segment, circle, box, polygon;
  combine with min/abs/subtract; transform with offset/rotate/scale.
  `color.shape@1` and presets (X, Cross, Ring pulse, Diamond).
- **Radial/angle centre setting.** Centroid (today), point, or offset from
  the centroid. Span (Selection/Fixture/Group) already exists.
- **2D fan.** A fan amount per axis of the plane, so one clip fans on two axes.
- **One Time source with a repeat on each source.** Time and Hit are the
  same system: a curve over one cycle; only the cycle length differs (the
  clip, or N beats). Merge them into Time with a repeat (off = over the clip;
  N beats = loop). The repeat lives on each source, so `color@1` loses its
  `every` input and each input keeps its own timing; the moving Space source
  gets its own `every` for strokes. Needs a small data migration
  (`hit` → `time` with a repeat). The UI chip reads "Over clip" or
  "Every 4 beats".
- **Grain as a general setting.** Grain (head, fixture, clump of N) says
  which heads share one value. Only Sparkle has it today. Move it next to
  Spans on the Space and random settings, so a chase or gradient can run by
  fixture and noise can be blocky. All heads in one unit take the value at
  the unit's centre.
