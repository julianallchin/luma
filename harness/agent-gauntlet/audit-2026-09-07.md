## Implemented

- One agent-facing physical stage frame for geometry and graph positions; measured node/assembly bounds, compact live summaries, separate fixture inventory and model search.
- A standard hanging-speaker-array function that composes existing primitives.
- Native atomic named-group creation/replacement and explicit additive generation available through Python. Unknown interactive highlight names produce actionable errors; known empty groups remain valid.
- Headless isolated-group, isolated-draft-clip and full-draft previews. Preview and apply use the same candidate preparation/validation, and images follow normal tool delivery and persistence.
- Concurrent independent child tools with ordered same-thread Python cells, automatic merges, bounded conflict-proposal inspection, accurate final-result reporting, and cancellation/reaping.
- More useful envelope diagnostics and less catalog/context duplication.
- Scoped DMX allocation preserving untouched stored addresses and pins; all-or-nothing allocation failure.
- Shared live/draft geometry parameter validation, including effective draft joint yaw.
- Canonical camera framing includes authored pieces and true transformed procedural bounds.
- Generated dispatch handlers use separate boxed helpers, preventing the default-stack MCP open crash found by the live harness.
- Cargo now watches bundled Python sources: a Python-only change triggers the rebuild required by the MCP freshness guard. A controlled modification-time probe verified that the documented rebuild actually repairs freshness.
