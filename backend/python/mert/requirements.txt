# Python dependencies for the shared MERT-95M feature-extraction worker.
#
# Pulls m-a-p/MERT-v1-95M from the HuggingFace cache (preloaded at app
# startup by `mert_preload.py`), runs the model on full-mix audio with
# overlap-add chunking, writes a per-track .npy cache. Both the bar
# classifier and the n2n drum-onset worker consume the cache.
#
# torch / torchaudio / torchvision are NOT pinned here — runtime/python.rs
# strips them at write time so the cu128 GPU wheels installed in step 1
# aren't overwritten by CPU PyPI wheels. transformers + accelerate pull
# torch transitively; pip respects the already-installed version.
#
# transformers stays below 5: MERT's remote code (modeling_MERT.py on the
# hub) subclasses transformers' HubertEncoder, which in v5 no longer collects
# hidden states itself, so `output_hidden_states=True` returns None and every
# track fails with "'NoneType' object is not subscriptable".
transformers>=4.41.0,<5
accelerate>=0.30.0
soundfile>=0.12.0
numpy>=1.24.0
